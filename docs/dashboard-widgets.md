# 仪表板自定义小组件

用户可按个人需要开关仪表板区块，偏好按用户（非租户）保存，团队内互不影响。

## 可配置小组件

| key | 区块 | 内容 |
|-----|------|------|
| `my_todo` | 待我处理 | 7 天内到期活动 / 停滞超 14 天商机 / 本周到期商机 |
| `analytics` | 阶段分布与最近活动 | 商机阶段分布条形图 + 最近活动列表 |
| `recent_opportunities` | 最近商机 | 最近 5 条商机表格 |
| `top_scored` | 高优先级商机 | 智能评分 TOP 5 |

统计卡片（公司数 / 线索数 / 商机总额 / 本月新增）与新手引导为固定区块，不可配置。

## 使用方式

1. 仪表板右上角点击「自定义」；
2. 在面板中点击小组件徽章切换显示 / 隐藏（高亮 = 显示）；
3. 即时生效并保存到当前用户，刷新页面保持。

## 实现细节

- 偏好存储：`users.dashboard_widgets`（JSON 数组，用户级）；
- `null`（从未自定义）= 全部显示；数组 = 仅显示白名单内的启用项；
- 切换动作白名单校验（`Dashboard::WIDGETS` 常量），非法 key 静默忽略；
- 服务端渲染时隐藏区块（`@if(in_array(...))`），隐藏的组件不执行对应查询，节省开销。

## 测试
