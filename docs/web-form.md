# 公共线索表单（Web-to-Lead）

无需登录的公共网页表单：访客在官网/落地页填写联系方式，自动进入租户线索列表，来源标记为 `web_form`。

## 访问入口

```
https://你的域名/f/{lead_form_key}
```

`lead_form_key` 为租户级 UUID，由租户管理员在「设置 → 租户设置 → 公共线索表单」生成。UUID 随机不可枚举，防止跨租户扫描。

## 使用流程

1. **生成链接** — 租户管理员进入「设置 → 租户设置」，点击「生成表单链接」；
2. **分享嵌入** — 将链接放到官网"联系我们"按钮、广告落地页等；可点「预览表单」查看访客视角；
3. **收集线索** — 访客提交后线索立即出现在「线索」列表，来源为 `web_form`、状态为 `new`，可直接走线索转换流程；
4. **停用/重置** — 点击「停用并重置」后旧链接立即失效（泄露或滥用时应急处理），可再生成新链接。

## 防滥用设计

| 机制 | 说明 |
|------|------|
| UUID 不可枚举 | `lead_form_key` 为 36 位 UUID，暴力扫描不可行 |
| 蜜罐字段 | 表单含视觉隐藏的 `website` 输入框；被填写即判定为机器人，**静默返回成功但不创建数据**（不泄露拦截逻辑） |
| IP 限流 | 路由层 `throttle:10,1`（每 IP 每分钟 10 次） |
| 表单验证 | 姓名必填、邮箱格式必填，字段长度限制 |
| 配额前置检查 | 提交前检查租户订阅状态与线索配额（表单提交、CSV 导入、页面创建入口一致拦截） |
| 一键停用 | 重置 key 旧链接立即失效 |

## 租户隔离与权限

- 提交数据通过 `tenant_id` 显式写入对应租户，经 BelongsToTenant/TenantScope 隔离，仅本租户可见；
- 生成/重置链接仅限租户 `admin` 角色（manager/sales 提示无权限）；
- 停用租户（`is_active = false`）的表单自动不可用，页面显示"表单暂不可用"。

## 降级行为

- 无效 / 已停用 key：页面正常渲染"表单暂不可用"，不报 404（不泄露 key 是否存在）；
- 租户配额满或试用过期：提交时提示"已达提交上限"，不创建数据；
- 审计：每次提交经 Auditable trait 记入审计日志（从被操作对象取 tenant_id，游客上下文安全）。

## 测试

`tests/Feature/WebFormTest.php`（12 项）覆盖：

- 管理员生成 / 重置链接；重置后旧链接失效；非管理员拒绝
- 有效 key 渲染表单；无效 / 停用租户显示不可用
- 游客提交创建 Lead（`source=web_form`、`status=new`、租户归属正确）
- 邮箱验证拒绝非法输入
- 蜜罐拦截（不创建数据）
- 线索配额满拦截；试用过期拦截
