# 界面多语言（i18n）— Phase 6 / P3

平台内置中文（`zh_CN`，默认）与英文（`en`）两套界面语言，基于 Laravel 原生 lang 文件实现，无外部依赖。

## 工作机制

```
请求进入
  └─ web 中间件组（bootstrap/app.php append）：BootstrapTenancy → SetLocale
       └─ SetLocale：若登录用户 users.locale 为 zh_CN / en 之一，
          则 App::setLocale($user->locale)，否则保持 config/app.php 的默认 locale
```

| 环节 | 说明 |
|------|------|
| 默认语言 | `config/app.php` → `'locale' => env('APP_LOCALE', 'zh_CN')`，默认中文，存量测试零回归 |
| 用户偏好 | `users.locale`（varchar(10) nullable，迁移 `2026_10_13_000005`），仅登录后生效 |
| 切换入口 | 侧边栏顶栏「语言」按钮，POST `/locale`（`locale.update`，auth 保护），写入当前用户偏好后回跳 |
| 参数校验 | `LocaleController` 校验 `in:zh_CN,en`，非法值 422 且不落库 |
| 游客页面 | 未登录不读用户偏好，跟随 `APP_LOCALE`（认证布局、错误页等） |

> `SetLocale` 挂在 web 组 append 末尾（BootstrapTenancy 之后），保证租户上下文已初始化；只对 `App\Models\User` 实例生效（避免_IMP 隐式模型等非用户对象误触发）。

## 语言文件结构

```
lang/
├── zh_CN/                  # 默认语言
│   ├── common.php          # 应用名、搜索占位、角色、退出登录等公共文案
│   ├── nav.php             # 侧边栏 12 个导航项 label + tooltip（含 *_hint）
│   ├── auth.php            # 登录页（欢迎语、表单标签、演示账号提示）
│   └── dashboard.php       # 仪表板（统计卡片、待办三栏、onboarding 步骤、阶段分布等）
└── en/                     # 英文（键与 zh_CN 完全一一对应）
    ├── common.php
    ├── nav.php
    ├── auth.php
    └── dashboard.php
```

键分组约定：

| 分组 | 覆盖范围 |
|------|----------|
| `common.*` | 应用名（app_name）、默认标题、当前租户、搜索占位、角色标签、用户下拉各设置项入口、退出登录、语言切换按钮 |
| `nav.*` | 平台租户管理 / 控制台 / 数据报表 / 审计日志 / 公司 / 联系人 / 线索 / 商机 / 看板 / 阶段 / 跟进活动 / 设置，每项含 `*_hint` tooltip |
| `auth.*` | 登录页全部文案（welcome_back / 表单 / 记住我 / 忘记密码 / 注册链接 / 演示账号） |
| `dashboard.*` | 页面标题、4 个统计卡片、待办三栏（到期活动/停滞商机/本周到期）及空态、阶段分布、最近活动、商机表列名、onboarding 5 步标签 |

### 已抽取范围

- `layouts/app.blade.php` — 页面标题、Logo 应用名、侧边栏全部导航与 tooltip、顶栏（当前租户/搜索/通知）、用户下拉菜单全部入口、语言切换表单、退出登录
- `auth/login.blade.php` — 登录页全量文案
- `livewire/dashboard.blade.php` + `app/Livewire/Dashboard.php` — 仪表板全量文案（含 onboarding 标签）

其余页面（列表/表单/详情/报表等）暂保持中文原文案，跟随本次抽取模式逐步补充即可；未命中 lang 键的页面在任何语言下渲染不变。

## 用户切换语言

```php
// 已登录用户（请求需 auth）
POST /locale
// 表单字段：locale=zh_CN | en
// 成功：回跳来源页 + session success；非法值 422
```

侧边栏顶栏的语言按钮即此表单的 UI 封装（hidden input 预填目标语言，中文界面显示「English」、英文界面显示「中文」）。

偏好持久化在 `users.locale`，下次登录自动生效；未选择过的用户（NULL）跟随 `APP_LOCALE`。

## 新增语言步骤

1. 复制 `lang/en/` 为 `lang/<locale>/`（如 `lang/ja/`），翻译键值；键结构必须与 `zh_CN` 一一对应
2. `app/Http/Middleware/SetLocale.php` 与 `app/Http/Controllers/LocaleController.php` 的白名单数组（`['zh_CN', 'en']`）加入新 locale
3. 顶栏语言切换表单的目标语言逻辑（`layouts/app.blade.php` 中 `app()->getLocale() === 'en' ? 'zh_CN' : 'en'`）按需扩展为轮换列表
4. `tests/Feature/I18nTest.php` 补充对应渲染断言

> 语言值会写入数据库并经 `in:` 白名单校验，两处白名单必须同步修改，否则新语言会 422。

## 测试

`tests/Feature/I18nTest.php`（6 用例）覆盖：

- 默认 locale 渲染中文布局（控制台/退出登录可见）
- 用户 `locale=en` 渲染英文导航（Dashboard / Log out）且不含中文文案
- `POST /locale` 切换 en 持久化、切回 zh_CN 持久化
- 非法值 `fr` 返回 422 且不落库
- 仪表板 onboarding 步骤标签跟随语言切换
